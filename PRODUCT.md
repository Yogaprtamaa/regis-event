
# Product

## Register

brand

## Users

Mahasiswa yang mendaftar event kampus IT FEST 6.0 (HIMTI). Konteks: browsing landing page dari HP/laptop, ingin cepat paham event apa ini dan langsung daftar. Ada juga panitia HIMTI yang pakai dashboard admin untuk kelola event dan pantau peserta, tapi itu surface sekunder — landing page publik adalah wajah utama produk.

## Product Purpose

Landing page + sistem registrasi untuk IT FEST 6.0, tema "Ride the Wave of Creativity" (sea-to-sand, tropis). Sukses berarti: pengunjung langsung ngerti event ini apa, kepincut vibe-nya, dan mendaftar tanpa hambatan. Dashboard admin di baliknya menangani monitoring kapasitas dan data peserta.

## Brand Personality

Ceria, energik, playful. Festival tropis kampus — bukan formal, bukan korporat. Warna berani (coral, lime, ocean blue, sunset orange) dipakai penuh percaya diri, bukan sebagai aksen malu-malu.

## Anti-references

Hindari tampilan generic SaaS/corporate: card grid seragam, hero-metric template, palette pastel cream/beige AI-default, eyebrow kecil di atas tiap section. Ini festival mahasiswa, bukan produk B2B.

## Design Principles

- Vibe dulu, form kemudian — tema tropis harus terasa dari layout dan tipografi, bukan cuma warna tempelan.
- Satu jalur jelas ke pendaftaran — jangan biarkan keceriaan visual mengaburkan CTA utama.
- Warna berani dipakai penuh (committed/drenched), bukan restrained minimalis.
- Landing page adalah wajah produk; dashboard admin melayani di belakang layar, prioritas desain lebih rendah.

## Accessibility & Inclusion

WCAG AA sebagai baseline. Reduced-motion ketat: setiap animasi (wave, scroll-reveal, dll) wajib punya alternatif `@media (prefers-reduced-motion: reduce)` yang instan/crossfade, karena landing page ini rencananya animasi-berat (tema ombak/sea-to-sand).
